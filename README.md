# Multi Downloader Pro

Modern single-page mobile-first downloader UI.

## Included
- YouTube search + in-app video player + available format links
- Instagram public media downloader
- Facebook public video/reel downloader
- X/Twitter media resolver
- Responsive 4-tab single-page design
- Personal photo/profile references removed

## Note
The front-end uses RapidAPI endpoints from the original project. For production, move API keys to a server-side proxy instead of exposing them in browser JavaScript.
